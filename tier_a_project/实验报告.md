## 摘要

本实验在 A 股日频多源数据上，构建了一条 **可复现、无未来信息泄露** 的深度学习量化流水线：对价量时序、截面基本面/资金流、新闻文本三类信息分别用 **GRU、MLP、哈希新闻编码器** 建模，经 **Spearman ICIR 定权的秩融合** 得到统一 alpha 分数，再映射为 **目标权重组合** 并完成 **T+1 历史回测**。  

在本机 RTX 3060 6GB 上，采用流动性 Top 500 股票、2020–2024 年样本，验证集（2024 年下半年）**全市场 mean IC = 0.026、ICIR = 0.195**；历史回测 **区间总收益 26.0%、复利年化 CAGR 60.0%、算术年化 54.3%、夏普 1.41、最大回撤 -15.5%**，同期沪深 300 区间总收益 13.1%、CAGR 28.5%、夏普 1.08。结果表明轻量多模态集成具备一定横截面排序能力；**IC 与组合收益衡量对象不同**，验证窗口较短时 CAGR 会被放大，结论需谨慎外推。模拟交易部分将在 FDL2026 比赛结束后补充。

**关键词**：面板数据、GKX 预处理、GRU、多模态融合、IC/ICIR、历史回测、T+1

## 一、任务背景与问题分析

### 1.1 作业背景

金融时间序列具有高噪声、非平稳、横截面异质性等特点。本次大作业要求完成：

1. **数据处理与特征构造**  
2. **深度学习模型设计与训练**（流程中必须包含神经网络）  
3. **交易策略与历史回测**  
4. **同花顺模拟交易（FDL2026）**  
5. **实验报告与反思**

给定 A 股日频量价及可选基本面、资金流、新闻数据，需利用过去一段 **特征序列** 预测 **未来短期收益方向**，并据此构建交易策略。

### 1.2 问题形式化

我们将任务定义为 **日频横截面排序（cross-sectional ranking）** 问题：

- 每个交易日 \(t\)，对股票池内每只股票 \(i\) 构造特征 \(X_{i,t}\)（含过去 \(L=20\) 日时序与当日截面特征）。  
- 预测标签为 **下一交易日相对沪深 300 的超额收益**：
  \[
  y_{i,t} = r_{i,t+1} - r^{mkt}_{t+1}
  \]
  其中 \(r_{i,t+1}\) 为 \(t\) 收盘至 \(t+1\) 收盘的收益率。  
- 模型输出连续分数 \(s_{i,t}\)，评价指标为 **Spearman IC**（\(s_{i,t}\) 与 \(y_{i,t}\) 的秩相关），而非单点方向准确率。

**为何用超额收益与 IC？**

- 超额收益削弱市场共同因子，更贴近「选股 alpha」。  
- IC 衡量 **相对排序** 能力，与「按分数高低调仓」的策略目标一致（参见 Gu, Kelly & Xiu, 2020）。

## 三、模型设计与方法论

### 3.1 总体架构

```
价量时序 ──► SeqGRU ──► z_A ──┐
截面因子 ──► TabMLP ──► z_B ──┼──► 秩融合 score ──► 目标权重 ──► 回测
新闻文本 ──► NewsHash ──► z_C ──┘
```

三路子模型 **独立训练**（Huber 损失，预测 `excess_ret_1d`），验证集上按各模态 **ICIR** 计算融合权重，再对预测做逐日 winsorize 与 **截面秩** 加权求和。

### 3.2 模态 A：SeqGRU（时序）

```text
Input: (batch, seq_len=20, n_seq=16)
GRU(hidden=128) → 取最后有效时间步
MLP: 128 → 32 → ReLU → Dropout(0.2) → 1
```

- **设计理由**：价量与衍生指标具有明显 **时间依赖**；GRU 参数量适中，适合日频短窗口。  
- **参考**：Deep learning in asset pricing 文献中时序编码常用 RNN/GRU/TCN；本方案为可复现基线。

### 3.3 模态 B：TabMLP（截面）

```text
Input: (batch, n_tab=9)
Linear(9→256) → ReLU → Dropout → Linear(256→64) → ReLU → Linear(64→1)
```

- **设计理由**：metric + moneyflow 以 **当日截面** 为主，MLP 足以刻画非线性；与 GKX 高维因子 + 神经网络思路一致。

### 3.4 模态 C：NewsHash（新闻）

- `use_news_bert: false`，不依赖 HuggingFace 大模型；  
- HashingVectorizer(256) → Linear → ReLU → Linear(32) → 1；  
- **2019 年前无新闻**：对应日期新闻特征为空，融合时 NaN 不参与加权（避免污染 score）。

### 3.5 训练设置

| 超参数 | 值 |
|--------|-----|
| 优化器 | Adam, lr=0.001 |
| 损失 | Huber(δ=1.0) |
| batch_stocks | 4096 |
| max_epochs | 10 |
| early stopping patience | 5（监控验证 IC） |
| seed | 42 |
| AMP | 开启（CUDA） |
| 可训练参数量 | GRU ~24 万；MLP ~7 万；NewsHash ~3 万 |

### 3.6 秩融合

1. 各模态预测 \(z\) 按日 winsorize；  
2. 映射为截面秩 \(rank \in [0,1]\)；  
3. 权重 \(w_A, w_B, w_C\) 由验证集 **ICIR** 归一化得到；  
4. \(\text{score} = w_A rank_A + w_B rank_B + w_C rank_C\)。

**本实验融合权重**（`fusion_weights.json`）：

| 模态 | 权重 | 解读 |
|------|------|------|
| A（GRU） | 0.629 | 时序价量主导 |
| B（MLP） | 0.364 | 基本面/资金流有效补充 |
| C（NewsHash） | 0.007 | 简单哈希新闻信号弱，几乎不参与 |

## 四、交易策略设计

### 4.1 与 PDF 示例的关系

PDF 推荐：**首日等权 n 只；之后每日卖得分最低 k 只、买得分最高 k 只**（\(n=5\text{–}30, k=1\text{–}5\)）。

本方案采用 **目标权重组合**（`src/strategy.py`），保留「按分数排序选股」核心思想，并增加：

| 机制 | 参数 | 作用 |
|------|------|------|
| 分数分位过滤 | `q_min=0.90` | 只在 Top 10% 分数中选股 |
| 持仓数量上限 | `n_max=30` | 对齐 PDF 的 n |
| 权重分配 | softmax(rank, τ=0.5) | 高分股权重更大（非严格等权） |
| 单票上限 | `w_max=5%` | 分散风险 |
| 行业上限 | `w_ind_max=25%` | 行业集中度控制 |
| 现金下限 | `c_min=3%` | 接近 PDF「尽可能满仓」 |
| T+1 | `sellable` 标记 | 当日买入次日才可卖 |
| 成本 | 佣金 0.015%、印花税 0.05%、滑点 0.05% | 贴近 A 股 |

`07_predict_latest.py` 在 **2024-12-31** 生成 `orders_20241231.csv`：

- 持仓 **30** 只；

## 五、评价指标定义（标准公式）

> 代码：`src/metrics.py`（IC）、`src/backtest.py` 中 `compute_metrics`（回测）。无风险利率 \(r_f=0\)。

### 5.0.1 IC / ICIR

- **日度 IC**：\(\mathrm{IC}_t = \mathrm{Spearman}(s_{i,t}, y_{i,t})\)，在当日横截面上计算；**意义**：分数与次日超额收益的排序相关性。IC≈0.03 表示「略优于随机」，不是「预测很准」。
- **mean IC**：有效交易日 IC 的算术平均。
- **ICIR**：\(\mathrm{mean(IC)}/\mathrm{std(IC)}\)（std 用 ddof=1）。**意义**：IC 的稳定性。
- **多空 spread**：每日 \(\bar y_{\mathrm{top}}-\bar y_{\mathrm{bot}}\)（top/bot 为 score 最高/最低 10%）；年化 = 日均 × 252。**意义**：头部是否跑赢尾部，更贴近「只买头部」的策略。

### 5.0.2 回测指标

设净值 \(P_t\)，日收益 \(r_t=P_t/P_{t-1}-1\)，有效交易日 \(n=124\)：

| 指标 | 公式 | 意义 |
|------|------|------|
| 总收益率 | \(P_T/P_0-1\) | 区间实际收益 |
| CAGR | \((P_T/P_0)^{252/n}-1\) | 复利外推到一年（短样本易偏大） |
| 算术年化 | \(\bar r \times 252\) | Sharpe 分子 |
| 年化波动 | \(\mathrm{std}(r_t)\sqrt{252}\) | 风险尺度 |
| Sharpe | \((\bar r\times 252-r_f)/\sigma_{\mathrm{ann}}\) | 单位风险超额收益 |
| 最大回撤 | \(\min (P_t-\mathrm{peak}_t)/\mathrm{peak}_t\) | 从高点最多跌多少 |

## 六、实验结果与对比分析

### 6.1 预测能力：IC / ICIR / Spread

| 指标（验证集） | 数值 | ICIR / 年化 | 天数 |
|----------------|------|-------------|------|
| 全市场 IC | 0.0259 | 0.195 | 124 |
| Top 10% 内 IC | -0.0192 | -0.114 | 124 |
| 多空 spread（日） | 0.277% | 年化 69.8% | 124 |

**分析**：全市场 IC 弱但为正；Top 10% 内 IC 为负说明「头部内部」次序噪声大，但不影响「头部 vs 尾部」的 spread；spread 显著为正，策略分组有效。

### 6.2 历史回测（验证集 2024H2）

| 指标 | 本策略 | 沪深300 | 说明 |
|------|--------|---------|------|
| 区间 | 2024-07-01 — 2024-12-31 | 同左 | 124 个交易日 |
| 总收益率 | **26.03%** | 13.13% | 区间实际 |
| CAGR | **60.01%** | 28.50% | 复利年化 |
| 算术年化 | **54.32%** | 28.51% | Sharpe 分子 |
| 年化波动 | 38.60% | 26.44% | |
| 夏普 | **1.41** | 1.08 | 标准公式 |
| 最大回撤 | **-15.53%** | -10.99% | |
| 期末净值 | 126.03 万元 | 113.13 万元 | |

### 6.3 为什么 IC 很低，年化却很高？（初学者版）

1. **IC 看 500 只全体排序，收益看实际买了哪 30 只**——不是同一指标。
2. **更相关的是 spread**：验证集高分组日均比低分组多 0.277%（年化约 69.8%），说明分组有 alpha。
3. **Top 10% 内 IC 可为负**：在已经很好的股票里再排序很难；策略只需「头部整体 > 尾部整体」。
4. **CAGR 60% 来自短区间外推**：半年实际总收益 26%；CAGR 是「若全年都这样复利」的 headline，会大于算术年化 54%。
5. **spread ≠ 组合收益**：实际只做多、有成本/T+1/换手约束，故总收益 26% 低于 spread 上限，属正常。

### 8.1 方案优点

1. **流程完整**：与课程 PDF 从数据到回测闭环一致，且模块化脚本可分工协作。  
2. **方法有依据**：GKX 预处理、IC 评估、多模态融合均有文献与业界对应。  
3. **可复现**：档位 A 在本机 6GB 显卡可稳定跑通，配置与产物路径清晰。  
4. **防泄露意识**：逐日截面变换、新闻时间映射、walk-forward 切分均落实到代码。

### 8.2 局限性与改进方向

| 局限 | 改进 |
|------|------|
| 股票池仅 500 只 | 服务器档位 C：Top 3000 + 多 seed |
| 新闻模态几乎无效 | RoBERTa-LoRA、事件分类、行业级聚合 |
| 验证期短 | 延长数据至 2025，增加 test 回测 |
| 策略非 PDF 原始 Top-k | 增加 Top-k 消融对比 |
| ICIR 偏低 | 更长 seq_len、Transformer、集成多 seed |

### 8.3 个人感悟

（请组员结合真实体会修改）

- 金融数据 **信噪比极低**，训练 loss 下降慢、IC 绝对值小是常态，不应单纯追求回测高收益。  
- **预处理与标签** 与模型结构同样重要；一次全样本标准化就可能造成「虚假夏普」。  
- 预测分数到 PnL 之间还有 **组合构建与成本** 一层；IC 与夏普可能背离。  
- AI 辅助编码提高了效率，但 **数据对齐、shift 方向、T+1** 等细节必须人工 review。
